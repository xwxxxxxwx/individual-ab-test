# A/B Test 数据分析

> 个人项目 | Python | 统计分析

## 项目简介
电商转化率 A/B 测试分析，通过假设检验和统计分析方法评估产品改动对用户转化率的影响。

## 技术栈
- Python (Pandas, NumPy, SciPy)
- Matplotlib / Seaborn 可视化
- Jupyter Notebook

## 分析内容
- A/B 测试数据清洗
- 转化率对比分析
- 统计显著性检验 (Z检验)
- 置信区间计算
- 用户分群效果差异

## 项目结构
- ab_data.csv - 原始数据
- ab_data_clean.csv - 清洗后数据
- AB_Test_Analysis.ipynb - 分析 Notebook
- scripts/ - Python 脚本
- notes/ - 笔记
- images/ - 图表

## 运行方式
pip install pandas numpy matplotlib seaborn scipy jupyter
jupyter notebook
